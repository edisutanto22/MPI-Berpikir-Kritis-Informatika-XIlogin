# MPI Berpikir Kritis — Informatika Kelas XI SMA

Media Pembelajaran Interaktif (MPI) berbasis HTML, CSS, dan JavaScript murni. Tidak memerlukan framework, server backend, atau API key.

## Fitur
- Materi inti: pengertian berpikir kritis, verifikasi sumber, bias dan argumen, serta pemecahan masalah.
- Modal materi yang interaktif.
- Laboratorium studi kasus dengan lima tantangan dan umpan balik.
- Checklist lima pertanyaan untuk memverifikasi informasi.
- Kuis otomatis 10 soal, skor 0–100, dan pembahasan.
- Refleksi peserta didik yang dapat diunduh sebagai file `.txt`.
- Desain responsif untuk komputer, tablet, dan ponsel.

## Cara menjalankan di komputer
1. Unduh atau ekstrak seluruh file.
2. Pastikan `index.html`, `style.css`, dan `script.js` berada dalam folder yang sama.
3. Klik dua kali `index.html` untuk membuka di Google Chrome.

## Cara mengunggah ke GitHub Pages
1. Masuk ke GitHub dan buat repository baru, misalnya `mpi-berpikir-kritis-xi`.
2. Pilih repository tersebut, klik **Add file → Upload files**.
3. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` (boleh unggah satu per satu atau sekaligus).
4. Klik **Commit changes**.
5. Buka **Settings → Pages**.
6. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
8. Tunggu proses publikasi. URL biasanya berbentuk `https://USERNAME.github.io/NAMA-REPOSITORY/`.

## Catatan
- Semua fitur utama berjalan di browser; tidak membutuhkan koneksi database.
- Google Fonts memerlukan internet. Jika font tidak termuat, halaman memakai font cadangan.
- Refleksi tidak dikirim atau disimpan ke server. Unduh file refleksi jika ingin menyimpannya.
- Ubah nama sekolah atau identitas pada `index.html` jika dibutuhkan.
